## Self-checklist (самопроверка перед сдачей)

Отметьте: ✅ / ❌. Воспроизведение — по `project/README.md`.

1. ✅ Сервис запускается по инструкциям из `project/README.md` и работает (есть рабочий сценарий).
2. ✅ Endpoint `/predict` (или `/search`) использует реальный retrieval-индекс (FAISS + эмбеддинги), не заглушку.
3. ✅ Есть EDA и хотя бы один эксперимент с метриками (в `project/notebooks/`).
4. ✅ Есть сравнение нескольких моделей/конфигураций по метрикам (таблица/график + выводы).
5. ✅ Код структурирован в `project/src/` (не только ноутбук).
6. ✅ Есть Dockerfile (или эквивалентная воспроизводимая инструкция без Docker).
7. ✅ Конфиги/секреты вынесены (есть `.env.example`), реальных секретов в репозитории нет.
8. ✅ Реализована базовая наблюдаемость (логи + `/health` и/или метрики).
9. ✅ В `project/report.md` есть обоснование выбора финальной конфигурации.
10. ✅ В `README.md` инструкция по воспроизведению (установка, запуск, ожидаемые артефакты).
